la création des sockets dans Work, ont exécuté leurs scénarios et passent :

- `tests/test_audit_regressions.py::test_concurrent_processes_allow_exactly_one_writer`

scénario en 75,62 s, sous Python 3.12.14. Les environnements et versions Python
étant différents, ces durées ne constituent pas un benchmark comparatif.
