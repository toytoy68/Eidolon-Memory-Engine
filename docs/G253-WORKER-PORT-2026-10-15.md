# G253 — Port limité pour la maintenance

Codex/GPT, 15 octobre 2026. Adoption de l'expérience Claude G236-7/0040 ; original conservé dans ses tests.

`IndexMaintenance` enveloppe désormais l'adaptateur dans `WorkerIndexView`. Le contrôleur, le worker et les deux scanners partagent cette même vue. Six membres explicites : identité du modèle/alias, génération active, preuve individuelle, upsert avec preuve et page d'inventaire. Les méthodes d'administration, recherche et accès au client ne sont pas exposées par la vue ; affectation/suppression d'attribut refusée. L'hôte garde son adaptateur administratif séparé, ses API historiques restent compatibles.

Les propriétés et méthodes délèguent à chaque appel : une génération changée extérieurement n'est pas masquée par un cache. Le contrôleur conserve ses contrôles de contexte, permissions, preuves, reprise et budgets ; la vue ne les remplace pas. Pas de mutation de schéma ni de checkpoint existant.

Sept sondes : cinq rouges avant code, deux contrôles existants verts ; après intégration, 92 tests de maintenance, reprise et contre-revue Claude réussissent avec `-W error`. Cycle complet et orphelin conservé vérifiés sur Qdrant local réel. La première implémentation frozen/slots provoquait un TypeError Python 3.12 à l'affectation d'un membre inconnu ; remplacée par une vue explicite à slots avec refus AttributeError, sans affaiblir les assertions.

La vue est une restriction de conception, pas un sandbox contre du Python malveillant : l'adaptateur privé peut être inspecté par du code dans le même processus. Les workers construits directement hors contrôleur restent sous responsabilité de leur appelant. Le xfail G220 Q2 sur l'adaptateur administratif n'est donc pas supprimé. Aucun service, suppression ou reconstruction déclenché par cette adoption. Qualification distante à récupérer avant bilan final.

## Complément de contre-vérification avant clôture

Une huitième sonde a reproduit un retour accidentel de `delete` lorsqu'un hôte fournit une sous-classe étendant la vue. Seule la classe exacte est désormais réutilisée ; toute extension est à nouveau enveloppée dans la vue limitée. Huit sondes et 93 tests ciblés réussis après correction, sans changer la limite de sécurité annoncée. La qualification distante finale doit porter sur ce complément.
